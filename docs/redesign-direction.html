01Principles

Seven rules that settle most arguments

Numbered because the brief numbers them and people cite them by number — not because they are a sequence. Any one of them can decide a layout on its own.

01

One font, one job.

EB Garamond carries everything narrative. Fira Mono carries everything functional. Fira Mono never sets descriptive text.

02

Three type levels per section. Never four.

The footer gets a column title, a link and a copyright line. That is the whole budget.

03

Spacing defines belonging.

The gap between a heading and its group must exceed the gaps inside it, or the group stops reading as a group.

04

Weight replaces size.

A label can be 12px and still read as a heading if it is bold, uppercase and letter-spaced. Reach for weight before points.

05

The image speaks, text whispers.

Hero text sits below the visual. Never inside it, never on it, never in a pill.

06

The heart is the campaign image.

It fills the stage the way Margiela's photography does. It never floats small in white space waiting for a photoshoot.

07

Whitespace needs something strong at its centre.

Empty room around a small element is not restraint. It is an unfinished page.

02Tokens
tokens.css

Five colours, six gaps

The red is an accent and nothing else — it belongs to the heart. It never becomes a button fill, a background or a hover state.

Category dividers only

--bg

The ground, everywhere

Swatches show true brand values in both themes — the site itself is white-ground only.

Check before you ship

--muted #8A8A8A on white measures 3.45:1. That clears AA for large text but not for the 14px menu descriptions, which need 4.5:1. Darkening the token to #767676 lands at 4.54:1 and is visually indistinguishable at 14px. Worth changing once, in the token, before it spreads.

Spacing scale

Six values, drawn below at their true size. Nothing between them exists. If a gap needs 30px, the answer is 24 or 40.

04Phase 0
Routing

Nothing here has a URL yet

This is the blocking item, and the diagnosis is narrower than the brief assumed. The homepage buttons are not dead — they call goTo() and swap a React state value. What is missing is the address bar.

—page is useState, never a route. No pushState, no router.
—The URL never changes, so nothing is linkable, shareable or bookmarkable, and Back leaves the site.
—Vite emits one index.html. netlify.toml has no SPA fallback, so a direct hit on /menu is a real 404.
—Our Story currently opens the Contact page — a leftover, not a design decision.

Fix

Give /menu, /story and /contact real routes, then add the fallback to netlify.toml so deep links survive a refresh: [[redirects]] from = "/*" · to = "/index.html" · status = 200. Test on the deployed URL — the dev server is forgiving in a way Netlify is not.

Asset — not a blocker

The brief expected the artwork to have the buttons baked in and asked for a clean re-export from the owner. It does not, and it does not need one. The buttons are DOM elements layered over a clean transparent image, and the original lives in the repo: brand-assets/HEART.zip → HEART/digital (RGB).png, 5788 × 5788, trimming to 3776 × 3173 of actual heart. The shipped Logo-1.webp is 1515 × 1540 — just under the 1600px minimum — so regenerate public/heart.webp from the original rather than asking for a new file. Trim the transparent padding first; the current asset is off-centre in its own box, which is why the buttons needed a hand-measured nudge.

07Menu
per category

Menu

620px column · zero item dividers

A menu is a list of things you might want, not a table of accounts. Removing the rule under every row and letting the name and description sit as one block turns a spreadsheet back into a card. Prices stay mono so the decimals line up.

—Column drifts right instead of centring
—A divider under every single item
—Descriptions set in Fira Mono, breaking the reading rhythm
—“BD” repeated on all fourteen rows

—No clearance from the content above it

09Order
of work

Build it in this order

Numbered because it genuinely is a sequence — each step depends on the one above it. A beautiful hero that leads nowhere is worse than a plain one that works.
